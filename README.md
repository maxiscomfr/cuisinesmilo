# Cuisines Milo

Crée un site vitrine pour "Cuisines Milo", un artisan cuisiniste (cuisines et dressings/placards sur mesure, pas de salle de bains) basé en Charente-Maritime (zone Royan).

Direction visuelle : sans-serif partout (Work Sans/Inter), contenu centré, sections avec bordures fines 0.5px, coins arrondis 8-12px, pas de dégradé ni ombre. Palette sobre : fond clair, texte sombre neutre, accent bois/brun chaud (#3C2A1E pour boutons, #8C6A45 pour labels). Grande zone photo hero, galerie réalisations en grille 2-4 colonnes avec placeholders images en attendant les vraies photos.

Pages : Accueil (hero titre "Des cuisines pensées pour durer, dessinées pour vous", CTA "Demander mon devis gratuit", 3 réassurances, aperçu réalisations, avis client), Cuisines, Dressings & Placards, Catalogue Armony Cucine (texte "catalogue en cours d'intégration, sous réserve d'autorisation du fabricant"), Réalisations (galerie filtrable Cuisine/Dressing), Avis clients, Contact (formulaire de devis détaillé + formulaire de contact simple, pas de prise de RDV avec agenda), Mentions légales.

Navigation en haut (Cuisines, Dressings, Réalisations, Avis, Contact), mobile-first, formulaires avec validation basique côté client.
